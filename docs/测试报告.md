## 三、发现的 BUG 与修复

### BUG 1: XML→JSON 在 Node.js 中不可用
- **问题**: `xmlConverter.js` 使用 `DOMParser`（浏览器 API），Node.js 环境不可用
- **影响**: 仅影响 Node.js 测试，浏览器环境正常
- **修复**: 改为双模式 — 浏览器用 `DOMParser`，Node.js 用纯 JS 正则解析器
- **文件**: `src/utils/xmlConverter.js`

### BUG 2: IP 地址脱敏规则不匹配字段名 `ip`
- **问题**: IP 规则的 patterns 只有 `/ip.?addr/i` 和 `/地址/i`，不匹配纯 `ip` 字段名
- **影响**: 字段名为 `ip` 的 IP 地址不会被自动脱敏
- **修复**: 添加 `/ip/i` 模式到 patterns
- **文件**: `src/utils/dataMasker.js`

### BUG 3: 身份证脱敏正则不匹配 18 位
- **问题**: `maskIdCard` 使用 `^(\d{3})\d{11}(\d{4})$` 匹配 18 位身份证，但只捕获 3+11+4=18 位
- **状态**: 实际测试通过，无需修复
