## 三、功能详细设计

### F1: JSON ↔ XML 双向转换

纯 JS 实现，无需额外依赖。

### F2: JSON ↔ YAML 双向转换

使用 js-yaml 库。

### F3: JSON ↔ CSV 双向转换

纯 JS 实现，支持自定义分隔符和嵌套扁平化。

### F4: JSON ↔ TOML 双向转换

使用 smol-toml 库。

### F5: 数据脱敏

纯 JS 实现，支持 6 种内置规则 + 自定义字段名匹配。

### F6-F8: UI集成

工具栏新增入口，面板复用现有布局模式。
