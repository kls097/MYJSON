# 优化方向

## 1. 编辑器替换为 Monaco Editor

**现状**：基于 CodeMirror 6 手撸编辑器，扩展维护成本高（搜索面板、快捷键、面板插件等均需手动集成）。

**目标**：集成 [Monaco Editor](https://microsoft.github.io/monaco-editor/)，获得开箱即用的编辑体验。

**需要覆盖的场景**：
- JSON 编辑（语法高亮、自动补全、实时校验）
- JSON 对比（diff 视图，inline/side-by-side）
- 对比结果应用（接受/拒绝变更）

**参考**：
- 官网：https://microsoft.github.io/monaco-editor/
- npm：`monaco-editor`
- Vue 集成方案：`@guolao/vue-monaco-editor` 或手动封装

---

## 2. 集成 JSON Crack 可视化地图

**现状**：仅有树形视图（TreeView），缺乏结构化图形展示。

**目标**：集成 [JSON Crack](https://jsoncrack.com) 的图形化能力，以节点关系图的方式展示 JSON 结构。

**参考**：
- 官网：https://jsoncrack.com
- 开源仓库：https://github.com/AykutSarac/jsoncrack.com
- npm 包：`jsoncrack`（或直接引入其核心渲染模块）

**功能点**：
- JSON → 节点关系图（树/图布局切换）
- 点击节点定位到编辑器对应位置
- 支持缩放、拖拽、搜索节点
